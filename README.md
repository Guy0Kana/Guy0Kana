## 🛡️ Mission

Make security smarter and easier to act on. I use **Python** to point machine learning at attacks, **C** to make robots and tiny devices behave, and **Swift** for iOS apps when I want something I can hold in my hand.

## 🔭 What I'm building

- 🧠 **Intrusion detection with ML**, including lightweight models that fit on edge and IoT devices
- 📡 **Threat intelligence**, turning public vulnerability data into clear priorities
- 🤖 **LLMs that can be trusted with security content**, with untrusted input fenced and outputs checked
- ☁️ **Self-hosted, hardened deployments**, from TLS and reverse proxies to locked-down web apps
