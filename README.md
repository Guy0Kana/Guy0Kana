# Guyo Kana

**Cybersecurity & Computer Networks Student | Machine Learning, Systems & Applied Tech**

I'm a third-year Cybersecurity and Computer Networks student at Strathmore University, interested in the intersection of security, machine learning and systems engineering.

Most of my work involves Python, networking, machine learning and building things that solve practical problems. I've worked on projects ranging from ML-based intrusion detection and software-defined networking to educational AI tools and IoT systems.

I'm also exploring autonomous systems, robotics and iOS development. I enjoy learning across disciplines, particularly where computing meets mathematics and engineering.

---

## Areas of interest

- **Cybersecurity:** Network security, threat intelligence, vulnerability assessment and cloud security.
- **Machine Learning:** Applied ML, anomaly detection and intelligent security systems.
- **Networks & Systems:** Software-defined networking, Linux, network automation and infrastructure.
- **Applied Engineering:** Robotics, autonomous systems, IoT and embedded computing.
- **Software Development:** Python, C/C++ and Swift.

## Selected projects

| Project | Description | Technologies |
|---|---|---|
| [Super Split](https://github.com/Guy0Kana/supersplit) | A vulnerability intelligence dashboard combining NVD, CISA KEV and EPSS data to assess and communicate security risks. Includes a threat-level indicator, security posture quiz and AI-generated briefs. | Node.js, Express, SQLite, Azure |
| [Edge-IoT-IDS](https://github.com/Guy0Kana/Edge-IoT-IDS) | Exploring lightweight machine learning approaches to intrusion detection for resource-constrained IoT devices, using the TON_IoT dataset. | Python, Jupyter, ML |
| [SynthNet](https://github.com/Guy0Kana/SynthNet) | An ML-assisted SDN system for traffic classification and QoS management in simulated campus networks. | Python, Mininet, Ryu, OpenFlow |
| [AI-Tutor](https://github.com/Guy0Kana/AI-Tutor) | An AI-powered educational assistant that adapts English curriculum content for Swahili-speaking learners, with summaries and revision support. | Python, FastAPI, LangChain, RAG |
| [Kenya FinAccess DataSprint](https://github.com/Guy0Kana/Datasprint2026-KenyaFinAccess) | Analysing Kenya's 2024 FinAccess survey data to model changes in financial status among Kenyan adults. | Python, Jupyter, Pandas |
| [AgriWeatherSensor](https://github.com/Guy0Kana/AgriWeatherSensor) | An IoT project collecting soil and weather measurements using ESP32 sensors and transmitting data over MQTT and HTTP. | ESP32, MQTT, IoT |
